# Открытые вопросы и решения, принятые по умолчанию

Разработка идёт, не дожидаясь ответов заказчицы. Там, где нужно её решение, в коде стоит разумное
значение по умолчанию, вынесенное в одно место. Когда появится ответ, меняем только это место.

| 3 | Вопросы безопасности в анкете и их формулировки | Три вопроса: беременность/ГВ, заболевания, опыт РПП (можно не отвечать) | `apps/student/src/pages/Onboarding.tsx` |
